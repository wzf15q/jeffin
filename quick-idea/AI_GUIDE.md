# QuickIdea AI 功能使用指南

## 🤖 AI 智能任务拆解功能

QuickIdea 现在支持 AI 驱动的任务拆解和智能日程规划！

### 功能特性

1. **智能任务分析** - AI 自动识别任务类型、领域和复杂度
2. **专家匹配系统** - 匹配 6 大领域专家提供专业建议
3. **任务拆解** - 将复杂想法拆解为 3-5 个可执行步骤
4. **智能排期** - 根据复杂度和优先级建议完成时间
5. **日历集成** - 一键导出到日历应用

---

## 🚀 快速开始

### 1. 配置 Gemini API Key

1. 访问 [Google AI Studio](https://aistudio.google.com/app/apikey) 获取免费 API Key
2. 在 QuickIdea 中点击右上角 ⚙️ 设置按钮
3. 在「AI 功能设置」中输入你的 API Key
4. 点击「测试 AI 连接」验证配置

> **提示**：Gemini API 提供每天 150 万 tokens 的免费额度，完全够个人使用！

### 2. 使用 AI 拆解功能

#### 方式一：自动提示（推荐）

1. 在输入框中输入想法，并添加 `#灵感` 标签
2. 系统会自动显示「需要 AI 帮你拆解吗？」提示
3. 点击「✨ AI 智能拆解」开始分析

#### 方式二：手动触发

1. 输入任何想法
2. 在设置中关闭「自动提示」
3. 手动点击 AI 分析按钮

---

## 📋 完整工作流

### 步骤 1：AI 分析

输入想法后，AI 会分析：
- **任务类型**：学习、工作、创意、生活等
- **领域**：具体所属领域（如编程、设计、写作）
- **复杂度**：简单、中等、复杂
- **预计耗时**：完成所需的总时间
- **匹配专家**：最适合的领域专家角色

**示例**：
```
输入：完成产品作业 #灵感
↓
AI 分析结果：
- 任务类型：学习
- 领域：产品设计
- 复杂度：中等
- 预计耗时：6 小时
- 匹配专家：📱 产品经理
```

### 步骤 2：查看拆解方案（可选）

如果 AI 判断任务需要拆解，你可以选择：
- **查看拆解方案** - 查看详细的执行步骤
- **直接保存** - 保存原始想法，不拆解

**拆解方案示例**：
```
专家：📱 产品经理

1. 研究产品场景分析方法 (2h) 🔴 高
2. 收集用户痛点案例 (1.5h) 🟡 中
3. 撰写解决方案 (2h) 🔴 高
4. 整理提交文档 (0.5h) 🟡 中

总耗时：6 小时
💡 执行建议：建议在 3 天内完成
```

### 步骤 3：录入日历

确认拆解方案后，系统会：
1. 根据复杂度和优先级**智能建议完成日期**
2. 显示距离现在的天数
3. 提供三种录入方式：
   - **iCal 文件**（推荐）- 下载后导入任何日历应用
   - **Google Calendar** - 直接添加（即将推出）
   - **飞书日历** - 直接同步（即将推出）

AI 会根据你的输入内容**自动匹配**最合适的专家！

## 💡 使用技巧

### 1. 输入技巧

**好的输入**：
- ✅ "学习 React 框架，做一个完整项目 #灵感"
- ✅ "设计新功能的用户界面 #灵感"
- ✅ "写一篇关于 AI 应用的技术博客 #灵感"

**不太好的输入**：
- ❌ "学习" （太简单，没有足够信息）
- ❌ "做项目" （太模糊，缺少具体内容）

### 2. 何时使用 AI 拆解

**适合拆解**：
- 复杂的学习计划
- 多步骤的工作项目
- 需要规划的创意任务
- 不确定如何开始的想法

**不需要拆解**：
- 简单的待办事项（如"买牛奶"）
- 单一步骤的任务
- 已经很明确的行动

### 3. 日历集成建议

- **iCal 文件**：适合所有日历应用（Apple 日历、Google 日历、Outlook 等）
- 下载后双击文件即可导入
- 支持自动设置提醒（提前 24 小时）

## 🔧 高级设置

### API 配置

- **API Key 存储**：本地存储，不会上传到服务器
- **自动提示**：可以在设置中关闭自动 AI 分析提示
- **测试连接**：随时测试 API 连接状态

### 数据隐私

- 所有任务数据存储在本地浏览器
- AI 分析时会将任务内容发送到 Gemini API
- Google 不会存储你的任务数据（根据 Gemini API 政策）

## ❓ 常见问题

### Q: Gemini API Key 如何获取？
A: 访问 https://aistudio.google.com/app/apikey，使用 Google 账号登录即可免费获取。

### Q: API 调用会产生费用吗？
A: Gemini 提供每天 150 万 tokens 的免费额度，个人使用完全足够。

### Q: AI 分析失败怎么办？
A: 
1. 检查 API Key 是否正确
2. 点击「测试 AI 连接」验证
3. 确保网络连接正常
4. 如果仍然失败，可以选择「直接保存」跳过 AI 分析

### Q: 可以修改拆解方案吗？
A: 当前版本暂不支持修改，但你可以：
- 选择「取消」重新分析
- 选择「直接保存」不使用拆解
- 保存后手动编辑任务

### Q: 日历录入支持哪些应用？
A: 当前支持：
- ✅ iCal 文件导出（通用格式）
- 🔜 Google Calendar（即将推出）
- 🔜 飞书日历（即将推出）
