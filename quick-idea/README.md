# QuickIdea - 快速想法管理

一个轻量级的个人任务管理工具，帮助你在 3 秒内捕捉灵感，0 思考完成任务管理。

## ✨ 功能特性

### 核心功能
- **快速输入** - 多行文本输入，支持标签分类
- **智能标签** - 一键插入 #想法 #任务 #灵感 #待办
- **任务管理** - 完成状态切换、删除、筛选
- **数据统计** - 实时显示总计、待办、已完成、今日任务
- **搜索筛选** - 关键词搜索 + 4 种筛选模式
- **通知提醒** - 晨间提醒（9:00）+ 晚间回顾（21:00）
- **数据管理** - 本地存储、数据导出、批量清除

### 🤖 AI 智能功能（新增）
- **AI 任务分析** - 自动识别任务类型、领域和复杂度
- **专家匹配系统** - 6 大领域专家提供专业建议
  - 👨‍💻 资深工程师 | 📱 产品经理 | ✍️ 内容策划师
  - 📚 学习教练 | 📊 项目经理 | 🎨 创意总监
- **智能任务拆解** - 将复杂想法拆解为 3-5 个可执行步骤
- **智能排期建议** - 根据复杂度和优先级建议完成时间
- **日历集成** - 一键导出到 iCal / Google Calendar / 飞书日历

> 💡 **AI 功能详细使用指南**：查看 [AI_GUIDE.md](./AI_GUIDE.md)
- 💾 **本地存储** - 数据保存在浏览器，完全私密
- 🎨 **现代设计** - Glassmorphism 风格，深色主题
- 📱 **响应式** - 完美适配手机和电脑

## 🚀 快速开始

### 本地运行

1. 克隆或下载项目
2. 在项目目录下启动本地服务器：

```bash
# 使用 Python 3
python3 -m http.server 8000

# 或使用 Node.js
npx serve

# 或使用 PHP
php -S localhost:8000
```

3. 在浏览器中访问 `http://localhost:8000`

### 添加到手机主屏幕

**iOS (Safari)**:
1. 点击分享按钮
2. 选择"添加到主屏幕"
3. 像 App 一样使用

**Android (Chrome)**:
1. 点击菜单按钮
2. 选择"添加到主屏幕"
3. 像 App 一样使用

## 📖 使用说明

### 快速输入

1. 在输入框中输入你的想法或任务
2. 使用标签进行分类：
   - `#想法` - 临时灵感
   - `#任务` - 需要完成的事项
   - `#灵感` - 创意点子
   - `#待办` - 今日必做
3. 点击"保存"按钮

### 任务管理

- **完成任务** - 点击任务前的复选框
- **删除任务** - 点击任务右侧的删除按钮
- **筛选任务** - 使用顶部的筛选标签
- **搜索任务** - 在搜索框中输入关键词

### 通知提醒

1. 点击右上角的铃铛图标
2. 允许浏览器通知权限
3. 设置中可以自定义提醒时间

**默认提醒**:
- 晨间提醒（9:00）- 显示今日待办任务
- 晚间回顾（21:00）- 总结今日完成情况

### 数据管理

在设置中可以：
- **导出数据** - 下载 JSON 格式的备份文件
- **清除数据** - 删除所有本地数据

## 🛠️ 技术栈

- **纯前端** - HTML + CSS + JavaScript
- **无依赖** - 不需要任何框架或库
- **本地存储** - 使用 localStorage API
- **通知 API** - 浏览器原生通知

## 📝 常见问题

**Q: 数据会丢失吗？**  
A: 数据保存在浏览器的 localStorage 中，除非手动清除浏览器数据，否则不会丢失。建议定期导出备份。

**Q: 可以在多个设备间同步吗？**  
A: V1.0 版本暂不支持，V1.2 将支持通过飞书多维表格实现云端同步。

**Q: 为什么通知没有生效？**  
A: 请检查是否允许了浏览器通知权限，以及浏览器是否开启了"请勿打扰"模式。
